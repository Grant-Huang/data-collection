# UI 设计规范：SLA 和评估规则的可视化

版本：v0.1  
日期：2026-10-07  
对应 PRD 部分：第 11 节（DAG 可视化）、第 11.4 节（交互层）

---

## 概述

本文档定义了如何在 DAG 图和节点详情面板中展示新增的 `sla_config` 和 `evaluation_criteria` 信息。

**设计目标**：
- 在主 DAG 图上一眼识别哪些节点有时间约束
- 点击节点可看到完整的 SLA 和评估规则
- 符合 PRD 11.2 的设计原则：一眼看懂、不需要图例也能猜出来

---

## 一级展示：DAG 图层

### 1.1 节点形态扩展

**原设计**（PRD 11.3）：按 `node_type` 区分形状和颜色

**新增**：在节点内添加 SLA 指示符

#### 有 SLA 的节点

```
┌──────────────────┐
│      初评        │
│   值班工程师     │
│   ⏱ 2h deadline │  ← 新增 SLA 标签行
└──────────────────┘
```

#### 无 SLA 的节点（保持原样）

```
┌──────────────────┐
│      分类        │
│      操作员      │
└──────────────────┘
```

### 1.2 SLA 标签的视觉编码

#### SLA 类型区分

| SLA 类型 | 图标 | 颜色 | 示例 |
|---|---|---|---|
| deadline（硬性）| ⏱ | 深红 (#DC2626) | ⏱ 2h deadline |
| target（目标） | 🎯 | 橙色 (#EA580C) | 🎯 2h target |
| warn_threshold | ⚠️ | 黄色 (#FBBF24) | ⚠️ 1.5h warning |

#### 标签位置

- 在节点内，位置：第三行（角色之下）
- 字体：11px，灰色文字 (#6B7280) + 图标
- 背景：与节点填充色一致（不加额外背景）

### 1.3 复杂 SLA 的简化显示

当 SLA 信息较多时（如同时有多个条件），主图只显示最关键的：

```
┌──────────────────┐
│     试产并      │
│   首件检验      │
│   ⏱ 4h deadline │  ← 只显示主要 SLA
│    🔄 Retry    │  ← 如果有 retry_semantics，加个小图标
└──────────────────┘
```

详细信息（具体的评估项、阈值等）留给详情面板。

### 1.4 移动端考虑

移动端 DAG 只读展示（PRD 2.2），同样应用 SLA 标签，但：

- 标签字体改为 10px（屏幕小）
- 如果节点太拥挤，SLA 信息可在缩放到详情时才显示

## 二级展示：节点详情面板

### 2.1 面板布局（桌面）

**触发方式**：点击 DAG 图上的节点

**展示位置**：
- 桌面：右侧滑出面板（PRD 11.4）
- 移动：底部半屏卡片（PRD 4.4.1）

**宽度**：桌面 320-400px（参考 PRD 第 3 节的右栏宽度）

### 2.3 各部分的详细设计

#### 2.3.1 时间约束部分

**样式**：

```css
.sla-section {
  border-left: 3px solid;  /* 左边框色区分类型 */
  padding-left: 12px;
  margin: 16px 0;
}

.sla-section.deadline {
  border-left-color: #DC2626;  /* 深红 */
}

.sla-section.target {
  border-left-color: #EA580C;  /* 橙色 */
}

.sla-section.threshold {
  border-left-color: #FBBF24;  /* 黄色 */
}
```

**显示内容**：

- SLA 类型：单选按钮形式（但只读），当前选中项加粗
- 时长：清楚的数字 + 单位
- 起点说明：下拉式解释，鼠标悬停显示详情
- 超期处理：枚举值，icon + 文字

#### 2.3.2 评估规则部分

**列表样式**：

每个标准为一个可展开的卡片：

```
┌─────────────────────────────────────────┐
│ [▼] ✓ 缺陷密度                [AND] ➕  │
├─────────────────────────────────────────┤
│ 类型: 数值指标                           │
│ 单位: defects/mm²                       │
│ 必填: ✓                                  │
│                                         │
│ 阈值:                                   │
│  • Normal (绿): < 10 defects/mm²       │
│  • Warning (黄): 10-20 defects/mm²    │
│  • Critical (红): > 20 defects/mm²    │
│                                         │
│ 说明: 检查单位面积内的缺陷数量           │
│                                         │
│ 逻辑关系 ➜ 下一项: AND                  │
└─────────────────────────────────────────┘
```

**交互**：

- 点击卡片标题展开/折叠详情
- 鼠标悬停在"AND/OR"上显示"这个条件与下一个条件是逻辑与/或"
- 鼠标悬停在指标说明上可看到完整的评估方法

#### 2.3.3 关联信息部分

其他部分（规则、返工条件等）保持 PRD 11.4 的既有设计，只是加入新的"时间约束"和"评估规则"两个小节。

## 三级展示：悬停和交互

### 3.1 DAG 图上的 Hover

参考 PRD 11.4 的路径高亮逻辑：

```
用户 Hover 节点 → 
  1. 该节点加深
  2. 上下游边和节点高亮（不透明度 100%）
  3. 其他节点/边降低不透明度（40%）
  4. 右下角浮出小提示：显示 SLA 摘要（如"⏱ 2h deadline"）
```

### 3.2 详情面板中的交互

- **点击"阈值"部分**：弹出小弹窗解释"Normal/Warning/Critical 分别代表什么"
- **点击"说明"部分**：若说明过长，展开全文
- **鼠标悬停 icon**：显示简短提示（如"⏱ icon 表示这是一个硬性截止时间"）

## 响应式设计

### 桌面 (≥ 1200px)

- DAG 图占主区域
- 详情面板宽 400px，右侧滑出
- 评估规则卡片宽度自适应

### 平板 (768-1199px)

- DAG 图占 60%
- 详情面板宽 40%，右侧并列
- 评估规则项目换行排列

### 移动 (< 768px)

- DAG 图全屏
- 详情面板改为底部 60% 高的半屏卡片
- 可左右滑动翻阅各部分（基本信息 → 时间约束 → 评估规则 → 关联规则）

## 颜色和文字规范

沿用 PRD 11.3 的设计原则：

### 颜色系统扩展

| 用途 | 颜色 | Hex | 用处 |
|---|---|---|---|
| 硬性Deadline边框 | 深红 | #DC2626 | SLA 类型 deadline 的左边框 |
| 目标时长边框 | 橙色 | #EA580C | SLA 类型 target 的左边框 |
| 预警阈值边框 | 黄色 | #FBBF24 | SLA 类型 warn 的左边框 |
| 必填指标 | 深灰 | #1F2937 | 对勾 + 粗体文字 |
| 可选指标 | 中灰 | #6B7280 | 对勾 + 普通文字 |
| 阈值等级-正常 | 绿 | #10B981 | 评估规则的 Normal 级别 |
| 阈值等级-警告 | 黄 | #F59E0B | 评估规则的 Warning 级别 |
| 阈值等级-严重 | 红 | #EF4444 | 评估规则的 Critical 级别 |

### 字体

- 部分标题：13-14px 加粗，色 #1F2937（深灰）
- 字段标签：12px 常规，色 #6B7280（中灰）
- 字段值：12-13px 常规，色 #111827（深灰）
- 说明文字：11px 常规，色 #6B7280（中灰）
- Icon：12-16px，颜色同文字

## 与现有设计的一致性

- **图形语言**：遵循 PRD 11.3 的节点形状/颜色规范，SLA 信息作为额外的文字标签而不是新的形状
- **交互模式**：保持"点击节点看详情"的既有逻辑，在详情面板中新增 SLA 和评估规则两个小节
- **信息优先级**：主图仅显示 SLA 摘要，详情留给面板，符合 11.2 的"渐进呈现"原则
- **颜色系统**：在既有 11.3 的颜色基础上，为 SLA 类型新增左边框色区分，不增加新的图标或符号数量
