# 协作工作流蒸馏数据集设计规范 v1.0

## 一、数据集分两类

### 1. 公共信息提取类 `public_extracted`
来源：公开案例、公开流程文档、论文、培训材料、公开SOP、公开网页等。

用途：
- 扩大样本覆盖面
- 验证算法对开放文本的迁移能力
- 作为弱监督或辅助实验集

注意：
- 可能存在流程概括过度
- 角色、系统、判断依据可能缺失
- 必须保留来源引用和出处

### 2. 真实专家采集类 `expert_collected`
来源：制造专家通过Wizard填写的真实工作流程。

用途：
- 主实验真实数据
- Gold Boundary/Role 标注
- 决策判断与经验蒸馏
- 跨行业、跨角色协作分析

实验规则：
- 两类数据默认分开跑、分开统计、分开报告
- 可支持“联合训练 + 分开测试”
- 不允许把两类测试集混成一个主结果

## 二、Dashboard 数据集评估维度

### 1. 覆盖度 Coverage
- 制造模式覆盖率
- 垂直行业覆盖率
- 场景类型覆盖率
- 四类流程类型覆盖率
- 岗位/角色覆盖率
- 系统/设备对象覆盖率

### 2. 平衡度 Balance
- 各制造模式样本偏斜度
- 各行业样本偏斜度
- 四类流程分布偏斜度
- 单一专家贡献占比
- 单一来源/企业占比

### 3. 流程完整度 Completeness
- 平均步骤数
- ≥5步样本比例
- 有明确触发条件比例
- 有明确结束条件比例
- 有角色信息比例
- 有系统/设备信息比例
- 有关键判断节点比例

### 4. 可抽取性 Extractability
- 步骤顺序明确率
- 单步动作清晰率
- 角色-动作可对应率
- 判断条件可解析率
- 模糊词/省略词比例
- 重复步骤/空步骤比例

### 5. 真实性与来源可信度 Authenticity
专家集：
- 专家岗位已知率
- 专家经验年限已知率
- 真实案例确认率
- 人工复核比例

公共集：
- 来源可追溯率
- 一手来源比例
- 原文引用完整率
- 人工复核比例

### 6. 标注成熟度 Annotation Readiness
- Gold Boundary覆盖率
- Gold Role覆盖率
- 双人标注比例
- 已仲裁比例
- 标注一致性，如 Cohen's Kappa / Boundary F1 Agreement

### 7. 多样性 Diversity
- 专家数量
- 岗位数量
- 流程长度分布
- 协作人数分布
- 系统组合数量
- 决策分支复杂度

### 8. 重复与泄漏风险 Leakage Risk
- 近重复流程比例
- 同模板改写比例
- 同一公开来源拆分出的高度相似样本比例
- Train/Test 高相似样本数量
- 同一专家跨训练/测试泄漏风险

### 9. 概览评分 Dataset Readiness Score
建议仅用于概览，不替代原始指标：

- 覆盖度 20%
- 平衡度 15%
- 完整度 20%
- 可抽取性 15%
- 来源可信度 10%
- 标注成熟度 10%
- 多样性 5%
- 低泄漏风险 5%

总分之外必须同时显示各维度原始指标。

## 三、标准 JSON 导入导出

### 导出支持
- 整个数据集导出
- 按 `source_type` 导出
- 按制造模式/行业/场景筛选
- `raw` 原始版
- `anonymized` 匿名版
- `role_normalized` 角色归一化版
- 可选包含/不包含 Gold Annotation

所有导出必须保留：
`dataset_meta.source_type`
和每条记录中的：
`provenance.source_type`

### 导入必须先预检，不直接入库

预检顺序：
1. JSON Schema 校验
2. source_type 一致性检查
3. 必填字段完整度
4. 制造模式/行业/流程类型合法值检查
5. Workflow step 顺序检查
6. record_id 重复检查
7. 近重复流程检查
8. 实体角色完整度检查
9. Gold 标注可用性检查
10. 自动生成数据集评估

### 导入报告至少显示
- 总记录数
- 可导入记录数
- 阻断错误数
- 警告数
- Coverage
- Balance
- Completeness
- Extractability
- Authenticity
- Annotation Readiness
- Diversity
- Leakage Risk
- Dataset Readiness Score

### 导入结论
系统可以给出数据用途建议：
- 可用于主实验
- 可用于辅助实验
- 需要人工补充后再用于实验

只有用户确认后才正式导入。

## 四、实验中心的数据选择规则

实验创建时必须先选择：
1. 数据源：公共信息提取 / 真实专家采集
2. 数据集
3. 切分方式：Train / Validation / Test
4. 输入版本：Raw / Anonymized / Role-normalized
5. 是否使用 Gold Annotation

默认推荐：
- 公共集单独跑
- 专家集单独跑
- 最终结果并排比较
- 联合训练时，测试集仍分别报告
